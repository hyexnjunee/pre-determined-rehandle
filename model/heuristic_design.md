# 휴리스틱 설계 노트: 수리모형에서 나오는 규칙 (2026-11-06, 고민 단계)

목표: Window–Slack v1/v2 처럼 "그럴듯한 규칙" 이 아니라, **수리모형의 목적함수와 제약에서 바로 유도한 규칙**으로
지원(누가 rehandle 을 하나)과 순서 교환(보완 ver)을 정한다. 롤링에서 이벤트마다 몇 ms 안에 돌 것.

## 1. 출발점: 순서가 정해지면 시각은 계산으로 끝난다
- 결정은 두 층이다. (가) 이산 결정: rehandle 배정 $x_{rv}$, 도와주는 크레인에서 끼울 자리 $y$, (보완 ver) 교환 $w$, 간섭 순서 $z$.
  (나) 시작 시각 $s$.
- (가) 가 정해지면 제약 (4)(5)(6)(8)(9)(11) 은 모두 "$s_j \ge s_i + $ 상수" 꼴 → **가장 이른 시작 = 최장 경로** (지금의 디코더가 하는 일).
- 목적 $\sum_j (\phi_j - a_j)$ 는 시작 시각에 대해 줄지 않는 함수라서, 순서가 같으면 가장 이른 시작이 최선이다.
  → 휴리스틱 = **이산 결정을 고르는 규칙 + 디코딩(O(n))**. 남은 질문은 "어떤 이산 결정을 바꾸면 목적이 얼마나 변하나" 뿐.

## 2. 한 수의 효과: 지연 전파 공식
한 크레인의 본 작업이 순서대로 $1,2,\dots$ 일 때, 작업 $m$ 이 크레인 때문에 늦게 시작하면(트럭이 이미 와서 기다림) **크레인 대기 작업**,
트럭이 아직 안 와서 $s_m = a_m$ 이면 **도착 대기 작업** 이라 하자. 작업 $k$ 의 시작이 $\Delta$ 만큼 당겨지면

$$\Delta W \;=\; \sum_{m \ge k} \Delta_m,\qquad \Delta_k=\Delta,\quad \Delta_{m+1} = \min(\Delta_m,\ s_{m+1}-a_{m+1}) \text{ (크레인 대기면)},\ 0 \text{ (도착 대기면)}$$

즉 **줄어드는 대기 = 당겨진 시간 × (그 뒤로 이어지는 크레인 대기 트럭 수)** 이다 (작은 $\Delta$ 에서 정확히 $\Delta \cdot N(k)$).
늦어지는 경우도 같은 꼴로, 앞 작업과의 빈틈 $g_m$ 이 지연을 흡수한다: $\Delta_{m+1}=\max(0,\Delta_m-g_m)$.
여기서 $N(k)$ = $k$ 부터 처음 도착 대기 작업 전까지의 크레인 대기 트럭 수 (job shop 의 critical block 과 같은 개념).

이 공식 하나로 연구 노트의 고민 ① 이 식이 된다: **대기열이 없으면($N=0$) 도와도 이득이 0** 이다.

## 3. 지원의 이득과 비용
rehandle $r$ (본 작업 $j$, 원래 크레인 $h$) 을 반대편 $g$ 가 맡으면

- **이득 (원래 크레인 쪽)**: $h$ 의 사슬에서 $r$ 이 빠져 $\Delta_h = p_r + t_{q r} + t_{r j} - t_{q j}$ 만큼 짧아진다.
  다만 $j$ 가 rehandle 이 아니라 자기 트럭 도착 $a_j$ 에 묶여 있으면 그만큼만 당겨진다:
  $\ \text{gain} \approx \min\big(\Delta_h,\ s_j - \max(a_j, \text{다른 하한})\big) \times N_h(j)$
- **비용 (도와주는 크레인 쪽)**: $g$ 의 두 작업 $k, k'$ 사이에 끼우면 사슬이 $c = p_r + t_{k r} + t_{r k'} - t_{k k'}$ 늘고,
  그 자리의 빈틈 $g_k$ 가 먼저 흡수한다: $\ \text{cost} \approx \max(0,\ c - g_k) \times N_g(k')$
- **조건**: $a_r \le$ 시작 (반출 = 트럭 도착 뒤, 적하 = AGV 도착 $H$ 전부터), $j$ 시작 전에 끝, 자리 (아래 규칙 3)
- **규칙**: $\text{gain} - \text{cost} > 0$ 인 것 중 가장 큰 것부터.
  가중 목적함수(예: 적하 트럭 가중 $\lambda$)로 바꾸면 $N$ 을 **가중 개수** 로 바꾸기만 하면 된다 → 외부트럭 양보 정도(발표 질문 2)를 규칙에 그대로 넣을 수 있다

이 추정은 $\Delta$ 가 빈틈보다 작고 상대 크레인과 간섭이 없을 때 정확하고, 아니면 이득은 위로 · 비용은 아래로 어림한 값이다.
그래서 **점수로 후보를 좁히고, 고를 때는 디코더로 정확히 계산**한다.

## 4. 지배 규칙 (계산 안 하고 버리거나 바로 고르기)
1. **원래 크레인이 놀면 돕지 않는다**: $C_q + t_{qr} + p(R_j) + t \le a_j$ 이면 원래 크레인이 $j$ 직전에 해도 $j$ 가 늦지 않음 → gain = 0.
   적하는 원래 크레인이 직전 본 작업 뒤에만 자기 rehandle 을 하므로(11′) 해측이 앞 작업들로 바쁠 때만 후보 (발표 16·17장)
2. **도와주는 크레인에 빈틈이 있으면 비용 0**: $[a_r, s_j)$ 안의 빈틈 $\ge p_r +$ 이동이면 $c \le g_k$ → cost = 0, 이득만 보면 됨
3. **자리**: 육측(LC)이 돕는 동안 $LC$ 위치 $\ge$ 그 시각 해측 위치 $+\delta$. 해측의 계획된 작업 구간들의 최대 bay $+\delta \le \min(b_j, \text{rh\_d})$ 인 시간대만 허용
4. **(보완 ver) 막힌 시간에 통째로 들어가면 무조건 교환**: $j$ 가 rehandle 때문에 $e_j$ 까지 못 시작하고, 바로 뒤 $k$ (적하끼리 아님) 의 트럭이 와 있으며
   $C_q + t_{qk} + p_k + t_{kj} \le e_j$ 이면 $k$ 를 먼저 해도 $j$ 는 안 늦고 $k$ 의 대기만 준다 → 교환 (단순 교환 논법, SPT 최적성 증명과 같은 꼴)

## 5. 상한 · 하한: 지원이 의미 있는 인스턴스 가리기
- **완벽 지원 하한** $LB_{free}$: 모든 rehandle 을 없애고(누가 공짜로 해 줌) 크레인끼리 간섭도 빼면, 순서가 고정인 크레인 두 대가 따로 도는 문제 →
  앞에서부터 계산하면 최적. 원래 문제의 완화이므로 협업 MIP(교환 없음) 목적값의 **하한**
- **지원 잠재력** $P = W_{무지원} - LB_{free}$ (둘 다 같은 방식으로 계산): 지원으로 줄일 수 있는 최대치.
  인스턴스마다 $P$ 를 먼저 계산하면 L1(적하 밀림 + LC 여유) 은 크고 R(대표) 은 작게 나올 것 → 결과 해석 · 인스턴스 분류에 바로 쓰임
- 휴리스틱 · MIP 의 **회수율** = (무지원 − 방법) / $P$ 로 비교하면 인스턴스 크기 · 부하가 달라도 같은 눈금
- 보완 ver 하한은 크레인마다 $K$ 칸 안 재배열 + 도착 시각 문제($1|r_j|\sum C_j$ 는 NP-hard 지만 $K \le 2$ 면 작은 DP)로 구할 수 있음

## 6. 알고리즘 틀
```
S ← 무지원 디코딩 (현재 운영)
반복:
  후보 rehandle = { r : N_h(j(r)) > 0 }                         # 지배 규칙 1
  각 r · 도와줄 자리 k 마다 조건(시각 · 자리, 규칙 3) 확인, 빈틈이면 비용 0 (규칙 2)
  점수 = gain − cost (2·3절 공식, O(1)) 로 상위 몇 개만 디코더로 정확 평가 (O(n))
  (보완 ver) 교환 후보: rehandle 로 막힌 j 와 바로 뒤 k (적하끼리 제외), 규칙 4 면 바로, 아니면 정확 평가
  가장 좋은 수 적용 · 개선 없으면 멈춤 (필요하면 tabu · 무작위 재시작)
롤링: 새 정보마다 현재 상태(확정 · 크레인 위치)에서 위 반복을 몇 ms
```
- 이웃은 "점수 > 0" 인 수만 → 임계 경로(critical block) 위의 수만 보는 것과 같다 (job shop 의 critical-path 이웃 축소와 같은 생각)
- Window–Slack v1/v2 와의 관계: v1/v2 는 규칙 1(원래 크레인 바쁨)과 규칙 2(빈틈이면 도움)만 쓴 특수한 경우.
  새 규칙은 **도와주는 쪽 비용**까지 넣어 "외부트럭이 얼마나 양보하나" 를 목적과 같은 저울로 재고, 교환을 같은 틀에서 다룬다

## 7. 확인 계획
1. **규칙이 MIP 를 설명하나**: 정적 협업 MIP 해에서 지원받은 rehandle 과 안 받은 rehandle 의 점수(gain − cost) 분포 비교 — 점수 > 0 쪽에 몰리면 규칙이 맞는 방향
2. **잠재력**: real2026 104개에 $P$ 계산, 그룹별 (L1 > L2 > L3 · L4 · R 예상), MIP 회수율과 상관
3. **성능**: real2026 3시간 · 5시간에서 휴리스틱 vs 정적 · 롤링 MIP (gap, 계산 시간), 지원만 / 교환만 / 둘 다
4. **가중 목적**: 적하 가중 $\lambda$ = 1, 2, 5 에서 AGV · 외부트럭 대기 변화 (발표 질문 2 답에 맞춰)

## 8. 정할 것
- 순서: 2절 공식 · 5절 잠재력부터 구현해 MIP 해로 검증(1·2) → 6절 반복 알고리즘 → 롤링
- 목적함수 가중 여부 (외부트럭 양보 한도)
- 교환을 휴리스틱에 넣을지 (현장 허용 여부와 같이)
